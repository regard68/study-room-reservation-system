# 共享自习室预约管理系统课程设计说明

## 1. 系统开发背景

高校自习室在考试周和课程空闲时段存在座位供需不均的问题。传统到场找座方式容易造成学生反复寻找、座位占用信息不透明等现象。因此，本项目设计一个结构适中、操作简单的共享自习室预约管理系统，使学生能够提前查看和预约座位，同时帮助管理员维护自习资源和预约秩序。

本系统以 JavaEE 课程所学知识为基础，重点体现 Spring Boot Web 开发、MyBatis 数据访问、MySQL 数据库设计、Session 登录验证和常见增删改查业务。

## 2. 系统需求分析

系统用户分为普通学生和管理员。

学生需要完成账号注册与登录，查看开放自习室及其座位，填写预约人姓名并按日期和时间段预约可用座位，查看或取消自己的预约，并查看系统公告。

管理员需要查看学生用户，维护自习室和座位信息，按学生、自习室、日期和状态查询预约，取消违规预约，并维护公告内容。

系统需要保证数据正确性。相同座位在相同日期和时间段只能存在一条有效预约；同一预约姓名在相同日期和时间段也只能预约一个座位。同一账号允许使用不同姓名为不同使用者预约。

## 3. 系统功能模块设计

### 3.1 登录注册模块

完成学生注册、学生与管理员登录、退出登录。密码经过 SHA-256 摘要后保存，登录成功后将用户信息保存到 Session。拦截器根据用户角色限制学生端和管理端页面访问。

### 3.2 学生预约模块

学生查看开放自习室和座位状态，填写预约人姓名并选择预约日期、座位与固定时间段。业务层在事务中检查自习室状态、座位状态、座位预约冲突和姓名预约冲突，再写入预约记录。

### 3.3 预约记录模块

学生查看个人账号提交的预约并取消未结束的有效预约。管理员查看全部预约，并可使用预约姓名或登录账号、自习室、预约日期和状态进行组合查询。

### 3.4 基础数据管理模块

管理员维护自习室和座位。座位增删后，系统自动重新统计对应自习室的座位数量，避免手工维护造成数据不一致。

### 3.5 公告管理模块

管理员完成公告新增、修改和删除，学生按发布时间倒序查看公告。

## 4. 数据库设计

系统使用 MySQL，包含五张核心表：

| 表名 | 说明 | 关键字段 |
| --- | --- | --- |
| user | 用户表 | username、password、role |
| study_room | 自习室表 | room_no、room_name、location、open_time、seat_count、status |
| seat | 座位表 | room_id、seat_no、status |
| reservation | 预约表 | user_id、reservation_name、room_id、seat_id、reserve_date、time_slot、status |
| notice | 公告表 | title、content、create_time |

自习室与座位是一对多关系，用户与预约是一对多关系，座位与预约也是一对多关系。预约表通过外键连接用户、自习室和座位。座位表使用 `(room_id, seat_no)` 唯一约束，防止一个自习室出现重复座位号。

## 5. 核心功能实现说明

预约功能是本系统的核心。`ReservationServiceImpl.reserve` 首先验证日期不能早于当天，然后检查自习室是否开放、座位是否可用。之后查询预约表：

```sql
SELECT COUNT(*) FROM reservation
WHERE seat_id = ? AND reserve_date = ? AND time_slot = ?
  AND status = 'RESERVED';
```

如果结果大于 0，系统提示“该座位当前时间段已被预约”。系统还使用以下查询检查预约姓名在同一日期和时间段是否已有有效预约：

```sql
SELECT COUNT(*) FROM reservation
WHERE reservation_name = ? AND reserve_date = ? AND time_slot = ?
  AND status = 'RESERVED';
```

因此，同一账号可以使用不同姓名预约，但同一姓名不能在同一时间段占用两个座位。检查和新增操作放在事务中，降低并发预约产生冲突的可能性。

页面使用 Thymeleaf 服务端渲染，统一采用蓝、白、浅灰配色。学生端强调快速选座，管理端使用表格和表单完成数据维护，整体操作路径短，适合课堂展示。

## 6. 系统测试

测试包括登录验证、注册重复校验、角色访问控制、自习室和座位增删改查、预约成功、座位冲突、姓名冲突、同账号不同姓名预约、预约取消和组合查询。详细步骤见 `docs/test-cases.md`。

## 7. 项目总结

本项目实现了共享自习室预约业务的主要流程，覆盖 JavaEE 课程常见的 MVC 分层、数据库关系设计、MyBatis 操作、Session 验证、事务处理和页面交互。项目结构清楚、功能数量适中，既能展示完整业务，又没有引入不必要的微服务或复杂中间件。

后续可以继续增加签到、预约超时、信用分和数据统计图表等功能，但当前版本已经满足课程设计的主要目标。
