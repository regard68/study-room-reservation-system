# 系统测试用例

| 编号 | 测试功能 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| TC-01 | 学生注册 | 输入新用户名和 6 位以上密码并提交 | 注册成功，自动进入学生首页 |
| TC-02 | 重复注册 | 使用已存在的用户名注册 | 提示“用户名已存在” |
| TC-03 | 登录验证 | 输入正确学生账号和密码 | 进入学生首页 |
| TC-04 | 错误密码 | 输入正确用户名和错误密码 | 提示“用户名或密码错误” |
| TC-05 | 角色权限 | 学生登录后直接访问 `/admin/home` | 自动跳转回学生首页 |
| TC-06 | 新增自习室 | 管理员填写完整信息并保存 | 列表出现新自习室 |
| TC-07 | 新增座位 | 管理员选择自习室并添加座位 | 座位列表和自习室座位数量同步更新 |
| TC-08 | 重复座位号 | 在同一自习室添加相同座位号 | 提示座位号已存在 |
| TC-09 | 正常预约 | 学生填写预约姓名，选择可用座位、当天或未来日期和时间段 | 提示预约成功，“我的预约”出现含预约姓名的记录 |
| TC-10 | 座位冲突 | 另一学生预约相同座位、日期和时间段 | 提示该座位已被预约 |
| TC-11 | 姓名冲突 | 使用同一姓名在相同日期和时间段预约另一座位 | 提示该姓名在当前时间段已有其他预约 |
| TC-12 | 不同姓名预约 | 同一账号使用两个不同姓名预约相同日期和时间段的不同座位 | 两次预约均成功 |
| TC-13 | 分时段预约 | 同一姓名分别预约 08:00-10:00 和 10:00-12:00 | 两次预约均成功 |
| TC-14 | 维护座位 | 管理员将座位状态改为维护中 | 学生端座位显示维护中且无法提交预约 |
| TC-15 | 学生取消 | 学生取消自己当天或未来的有效预约 | 状态变为已取消，座位可再次预约 |
| TC-16 | 越权取消 | 学生构造请求取消他人预约 | 系统拒绝并提示无权操作 |
| TC-17 | 预约查询 | 管理员输入预约姓名或账号并选择日期、状态 | 仅显示符合条件的记录 |
| TC-18 | 公告管理 | 管理员新增、修改、删除公告 | 学生公告页与后台数据保持一致 |

## 答辩演示建议

1. 使用学生账号展示自习室列表并完成一次预约。
2. 使用同一姓名再次预约相同时间段，展示冲突提示。
3. 改用另一个姓名预约同一时间段，展示预约成功。
4. 进入“我的预约”取消刚创建的记录。
5. 使用管理员账号新增一个自习室和座位。
6. 展示预约组合查询与公告发布。
